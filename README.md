# CNC Control STM32 — пульт керування для FluidNC

Окремий пульт (контролер інтерфейсу) на **STM32F103CBT6** (Blue Pill) для керування ЧПУ / лазерним верстатом під прошивкою **FluidNC** на ESP32. Пульт має кольоровий TFT-дисплей, клавіатуру на **TM1638**, читає G-code з SD-карти FluidNC і вміє показувати та обводити габаритний прямокутник (bbox) завдання ще до запуску.

## Можливості

- Живе відображення стану: `IDLE / RUN / HOLD / JOG / HOME / ALARM / NO LINK`, машинні та робочі координати (MPos / WPos), F і S, поточний файл і прогрес.
- Ручний джог осей X / Y / Z з кроками `0.1 / 1 / 10 / 100` або безперервним рухом.
- Нуль осей (XY0, Z0, окремо X/Y/Z), `G10 L20` для встановлення робочого нуля, пробування висоти інструмента (`G38.6`), `$H` і `$X`.
- Оверрайди подачі та шпинделя / потужності в режимі RUN, кнопки HOLD / START / RESET.
- Перегляд списку файлів на SD-карті та запуск обраного файлу.
- **Сканування bbox** файлу: пульт читає перші рядки файлу через `$ESP222` і шукає заголовок `; Bounds:` (LightBurn). Якщо заголовка немає, робиться повний парсинг G-code (лише для файлів розміром до безпечного порогу).
- **Прев'ю / обвід периметра** (trace): обвід прямокутника bbox на поточній Z з окремою швидкістю і потужністю. Підтримує профілі SPINDLE та LASER.
- Профілі SPINDLE / LASER зі збереженням налаштувань (подача, потужності, швидкість і потужність обводу) у flash-пам'яті МК.
- Автоповтор для осьових кнопок (утримання).

## Апаратна частина

| Компонент | Призначення |
|---|---|
| STM32F103CBT6 (Blue Pill) | Головний контролер пульта |
| ILI9341 (SPI TFT) | Дисплей |
| TM1638 (модуль кнопок і світлодіодів) | Клавіатура |
| ESP32 з FluidNC | Контролер верстата |

### Підключення (за `board.h`)

| Сигнал | Пін STM32 |
|---|---|
| LCD CS | PA3 |
| LCD DC | PA2 |
| LCD RST | PA0 |
| SPI1 SCK / MOSI | PA5 / PA7 |
| TM1638 STB | PC13 |
| TM1638 CLK | PC14 |
| TM1638 DIO | PC15 |
| UART до FluidNC: USART1 TX / RX | PA9 / PA10 (115200 бод) |

Підключіть GND пульта і ESP32 разом, інакше обмін по UART працюватиме ненадійно.

## Підготовка FluidNC (обов'язково)

Пульт використовує команди, яких немає у стандартному FluidNC:

- `$ESP220=sd/<файл>` — запуск файлу з SD;
- `$ESP222=<N>,sd/<файл>` — читання перших N рядків файлу у JSON (для пошуку `; Bounds:`);
- `$ESP210` — запит, який пульт надсилає при старті.

Є два варіанти:

1. **Готова прошивка.** Використайте `fluidnc_v4.0.5_pre2_esp222.bin` з цього репозиторію (патчена збірка з командою `ESP222`).
2. **Власний патч.** Опис змін у файлі `Патч FluidNC.txt`. Суть: у `FluidNC/src/FileCommands.cpp` для команди `File/ShowSome` додається alias `ESP222`. Команда читає лише потрібну кількість рядків і не викликає Soft Reset, тож банер `[MSG:RESET]` не з'являється.

Перевірте в FluidNC, що файли з SD видно і запускаються з веб-інтерфейсу, перш ніж підключати пульт.

## Збірка та прошивка пульта

Проєкт створено в **STM32CubeIDE** (конфігурація в `cnc_control_stm32.ioc`).

1. Відкрийте папку проєкту в STM32CubeIDE (`File → Import → Existing Projects into Workspace`).
2. Зберіть конфігурацію `Debug` (`Project → Build Project`). Готові файли вже є в `Debug/`: `cnc_control_stm32.elf`, `.hex`, `.map`.
3. Прошийте через ST-Link (`Run → Debug` або STM32CubeProgrammer) або через USB-UART з bootloader.

Налаштування зберігаються на сторінці flash `0x0800F800`. Якщо змінюєте формат структури в `settings.c`, змініть `MAGIC`, щоб старі дані скинулися.

## Структура проєкту

```
Core/Src, Core/Inc     — код застосунку
  main.c               — ініціалізація периферії (SPI1, USART1, DMA, GPIO)
  ui.c / ui.h          — екрани, меню, обробка кнопок
  fluidnc.c / .h       — UART-протокол з FluidNC, статус, команди, SD-список
  bbox.c / .h          — сканування файлу і визначення габаритів
  settings.c / .h      — збереження налаштувань у flash
  ili9341.c / .h       — драйвер дисплея
  tm1638.c / .h        — драйвер клавіатури
  board.h              — призначення пінів
  font5x7.h            — шрифт
Drivers/                — HAL та CMSIS (ST)
Debug/                  — артефакти збірки STM32CubeIDE
fluidnc_v4.0.5_pre2_esp222.bin — прошивка FluidNC з патчем ESP222
Патч FluidNC.txt        — опис патча
```

## Використання

1. Підготуйте файл у LightBurn або slicer і скопіюйте на SD-карту верстата.
2. На пульті відкрийте список SD (кнопка SD).
3. У списку: **Y+ / Y-** — вибір файлу, **XY0** — запуск файлу, **Z0** — сканування bbox, **RST** — назад.
4. Після сканування пульт показує розміри (`X`, `Y`, `SIZE`) і джерело: `(header)` — з заголовка `; Bounds:`, `(parsed)` — з повного парсингу.
5. На екрані прев'ю: **Y+ / Y-** — швидкість обводу, **Z+ / Z-** — потужність (лише в профілі LASER), **XY0** — запуск обводу периметра, **Z0 / RST** — назад.
6. Керування під час роботи: HOLD (`!`), START (`~`), RST (soft reset, `0x18`).

## ⚠️ Безпека

- **Перед будь-яким рухом перевірте режим.** Пульт зберігає профіль SPINDLE / LASER між сесіями. Обвід периметра може надсилати `M3` (увімкнення шпинделя або лазера) незалежно від профілю, тому переконайтеся, що інструмент відповідає файлу, перш ніж натискати XY0 на прев'ю.
- **Лазер:** завжди надягайте захисні окуляри, не залишайте лазер без нагляду і перевіряйте обвід на холостому ході (без увімкненого лазера або з мінімальною потужністю).
- **Фреза:** перед запуском переконайтеся, що заготовка закріплена, а висота Z безпечна. Функція пробування (`G38.6`) рухає інструмент до датчика, тож перевірте шлях.
- Пульт не замінює аварійну кнопку верстата. Використовуйте апаратний E-stop.

## Відомі обмеження

- Файли без заголовка `; Bounds:` розміром понад поріг не сканується, бо великі читання з SD без заголовка можуть зависнути FluidNC. Такий файл отримає статус `TOO BIG`.
- Коректність bbox для файлів з `G91` (відносні координати) залежить від того, що заголовок `Bounds` є відносним розмахом від точки старту.
- Частина написів і коментарів у коді українською мовою.
- Кнопка RST надсилає soft reset (`0x18`) — не використовуйте її в середині руху без потреби.
